# Exploratory Data Analysis (EDA) Project

This project analyzes the Diabetes dataset distributed with scikit-learn.

## Analysis
- Dataset inspection
- Missing values and duplicates
- Statistical summaries
- Distributions
- Correlation analysis
- Correlation heatmap
- Scatter plots
- Key findings and conclusion

## Files
- `eda_project.ipynb`
- `eda_diabetes_dataset.csv`
- `README.md`
- `requirements.txt`

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
